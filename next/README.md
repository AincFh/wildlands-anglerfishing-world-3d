# WILDLANDS NEXT · 山野钓行（3D 引擎重建预览）

这是新的 **Three.js / WebGL2** 分支，不再基于旧版手写 WebGL 几何渲染。它与原版游戏分开：旧版入口仍在仓库根目录，新版位于 `/next/`。

## 当前可玩的内容

- 动态湖泊：水面法线、镜面环境反射、风与天气、日夜和生态鱼群。
- 山岸场景：林木、三处登陆点、实体岩石、芦苇、林下草丛、漂流木。
- 第一人称：桌面 WASD、鼠标拖动环顾；窄屏/触摸设备可使用屏幕方向键。
- 钓鱼：长按蓄力、按方向计算实际水面落点、抛投飞行、鱼漂等待、咬钩窗口、扬竿、张力/泄力控制、线断与脱钩、鱼获结算。
- 8 种鱼：本地生成的真实 3D 鱼身轮廓、鱼鳍、鱼眼与鳃线，并有钓获时的立体展示。
- 图鉴、4 档钓竿、金币与自动存档；音效、森林环境声及开关。

## 3D 鱼体建模与动态游动升级

- 鱼种不再只是同一条鱼的不同颜色：八种鱼具有独立长宽、躯体高度和尾鳍比例。北方狗鱼更细长，鲤鱼较高厚，鲟鱼更长、体态更贴底。
- 实际 3D 几何体拥有绕尾柄旋转的分叉尾鳍关节以及左右胸鳍关节，不再通过整个鱼体持续自转来模拟游动。
- 搏鱼时尾鳍根据时钟和挣扎强度摆动；上岸展示时使用较平缓的尾鳍/胸鳍运动及轻微躯体摆动。
- 动画计算与鱼种比例由 `src/sim/fishMotion.mjs` 提供纯数学驱动，并由 Node 单测和真实 WebGL 浏览器的网格姿态变化验收。
- 仍属于程序化美术资产；此更新提升了轮廓差异与动作逻辑，但不将其描述为商业 3A 模型或真实生物力学仿真。

## 新增：真实饵料生态

- **通用溪饵**：无限免费，适合新手，鱼群分布偏常见品种。
- **天然蚯蚓**：90 金币购买 8 份；咬钩更快，黄鲈、鲤鱼权重增加。
- **银色亮片**：280 金币购买 6 份；吸引狗鱼、湖鳟和帝王鲑。
- **深水钓组**：520 金币购买 5 份；在湖中央深水和岬角更易遇到湖鲟、鲑鱼，等待稍长。

饵料在鱼漂**真正落入湖水时**才消耗；无效抛投不会扣库存，投出后的鱼种分布由实际所用饵料、落水深度和钓点决定，切换装备不能作弊改动已发出的抛竿。鱼群权重与购买、装备、扣减、旧存档兼容均为纯函数并通过可重复随机种子测试；真实 Chrome Playtest 还会完整走购买→装备→抛竿→消耗流程。

## 结构和运行要求

- `src/world/*`：湖面、天气、天空、森林和岸线场景。
- `src/angler.js`：可操作的钓鱼流程、渔具与存档。
- `src/world/fishModel.js`：本地 parametric 鱼体 3D 模型。
- `src/world/shoreDetails.js`：实例化岸边植被/岩石/漂流木。
- `tests/next_browser.py`：真实 Chrome/Selenium/WebGL 浏览器验收。
- `../.github/workflows/next-smoke.yml`：自动化验收及截图产物。

Three.js 运行时现由 **npm 固定版本 0.179.1 构建时打包到本站 `/next/vendor/three/`**，游戏运行**不再依赖外部 Three.js CDN**。仍要求 WebGL2；本地运行需先在仓库根目录执行 `npm install --no-audit --no-fund`、`npm run vendor:three`、`npm run verify:three`，再以 `python -m http.server 8080` 提供本地 HTTP 服务并打开 `/next/`。不能双击 HTML 使用 ES 模块。GitHub Actions 构建、浏览器测试、部署均使用同一固定版本，MIT 许可附带于 vendor 目录。可选外部钓竿 GLB 和树木模型仍受各自服务商网络状况影响，但默认不请求它们。

## GitHub Pages 静态缓存与发布一致性

GitHub Pages 对静态脚本有浏览器缓存。只给 HTML 添加 `?v=...` **不能刷新内部的 ES Module 导入**，这曾造成发布了新的鱼模型，玩家仍收到旧版动作逻辑。现在发布流水线运行 `scripts/version-next.mjs`，把整个 `dist/next/src/**` 依赖图里的相对模块 URL 统一改为当前 Git commit 的固定 `?v=<12位 SHA>`。原始源码保持可读、无发布参数，生产构建和真正的 Chrome/WebGL 验收使用同样的版本化目录。Three.js 自身由于版本锁定并本地化，可继续复用固定依赖缓存。

## 性能与限制

这是**独立重建中的可玩公开预览，不是完成的商业级游戏**。真实鱼模型仍属于程序化造型，并非摄影测量或专业美术师制作的骨骼资产；森林也未达到大型商业 3D 游戏的植被复杂度。软件 GPU 的截图与帧率不能代表独立显卡实测性能。

为避免第三方 GLB 的 CORS 错误，外部树木模型默认禁用。可显式增加查询参数 `externalTrees=1` 尝试加载，但第三方服务器仍可能阻止跨域访问。钓竿外部 CC0 模型同样仅在 `rod=kit` 时尝试；默认使用本地可运行的碳纤维造型。
